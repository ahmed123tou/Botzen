🤖 Botzen Bot Setup

STEP 1 / 5

Open Discord Developer Portal

Open the Discord Developer Portal and select the application containing your bot.

STEP 2 / 5

Open the Bot section

Inside your application, select Bot from the menu.

Make sure your application actually has a Discord bot.

STEP 3 / 5

Enable the required intents

In the Bot page, enable the intents your bot requires for the features you plan to use.

Botzen can add more required intents later as dashboard features are implemented.

STEP 4 / 5

Copy your bot token

In the Bot section, use the token controls to copy the bot token.

⚠️ Never post your bot token in Discord, GitHub, screenshots, or public websites. If somebody gets the token, regenerate it immediately in the Discord Developer Portal.
STEP 5 / 5

Bot token

You completed the tutorial. You can now securely send the token to Botzen.

🔒 The token is sent directly to the Botzen backend for validation. It is never saved in browser localStorage.
